## Idea del paper en tres líneas

1. Se fija una familia concreta de "nudos recursivos": K_0 es un círculo; K_d es el patrón tórico (p_d, q_d) colocado sobre el tubo de radio r_d alrededor de K_{d−1}, usando un marco de Bishop (de rotación mínima) cerrado con un giro lineal y normalizado por N_{d−1}(0) = proyección de e_z (Def. 2.1, fijada en la ronda 3). Por defecto (p, q) = (2, 3) y r_d = f · grosor(K_{d−1}).
2. Se demuestra lo elemental: K_d es una curva cerrada suave y embebida si r_d < grosor(K_{d−1}) (Lema 3.1); el marco cerrado tiene número de enlace Wr − α/2π con su núcleo, lo que identifica K_d como el cable (p, q + p·Lk) de K_{d−1} (Lema 3.2); p L(K_{d−1})(1 − r κ_max) ≤ L(K_d) ≤ p L(K_{d−1})(1 + r κ_max) + r(2πq + p|α|) (Lema 3.3); y, para p = 2, grosor(K_d) ≤ r_d, de donde Rop(K_d) ≥ L(K_d)/r_d (Prop. 3.5, cota inferior interna a la familia). De la cota inferior grosor(K_d) ≥ min(τ − r, c r sin(π/p)) con p = 2: en la familia (2,3) con f ≤ 1/2 **todo par doblemente crítico** de K_d con bases distintas —en hebras distintas (Lema 3.7, constante c_1 ≥ 1/2) o en la misma hebra (Prop. 3.10 y Cor. 3.11, c_0′ ≥ 1/2, por un argumento de giro)— está a distancia ≥ min(2(τ − r), r), **en toda profundidad y sin hipótesis adicionales**. Por tanto (H_c) con c = 1/2 queda **demostrada en d = 1** (grosor(K_1) ≥ r_1/2 para todo f ≤ 1/2) y, para d ≥ 2, **reducida a la cota de curvatura** minRad(K_d) ≥ r_d/2, que se deduce de una hipótesis (H_3) sobre las derivadas de la velocidad y del vector de curvatura del marco paralelo de la base (Prop. 3.8, Teorema 3.12); sin (H_3) ninguna constante funciona para una base arbitraria (Obs. 3.13). **Ronda 3 (resultado parcial):** la velocidad y la curvatura de K_d se controlan con los datos de (H_3) de K_{d−1} en forma de longitud de arco (ν, μ; Lema 3.14, Prop. 3.15), y para d ≥ 3 basta la condición de crecimiento explícita (12) del Cor. 3.16, que combina ambos términos (cada umbral, 0.0336·4^d para ν y 0.0504·8^d para μ, es el que corresponde cuando el otro término es nulo). La Prop. 3.17 demuestra que ν, κ_max pasan de un nivel al siguiente pero μ(K_d) **no puede acotarse con ninguna función localmente acotada de los datos (H_3) de una base arbitraria** (se pierde una derivada por nivel en ese sentido); no es un resultado negativo sobre la familia, donde μ crece despacio (4.5 → 7.0 de d = 1 a 4, valores lisos). **Ronda 4:** el caso d = 2 queda demostrado mediante una **prueba asistida por computador** (aritmética de intervalos sobre la base explícita K_1, revisada por un árbitro interno independiente en la ronda 5; no es una verificación formal: r_2 κ_max(K_2) ≤ 1.187, luego minRad(K_2) ≥ 0.842 r_2 y grosor(K_2) ≥ r_2/2 para todo f ≤ 1/2 y toda elección de fases; Prop. 3.19), así que (H_c) con c = 1/2 vale en d ≤ 2 y el Cor. 3.22 es incondicional para d ≤ 2; **(H_3) uniforme en d (y con ello d ≥ 3) sigue abierto**. Bajo (H_c), Rop_d ≤ 2π Λ_Rop^d con Λ_Rop = 𝒜/γ explícito (Λ = 20 para (2,3), f = 1/2, c = 1/2; Λ = 10 con c = 1).
3. Numéricamente, polígonos explícitos de hasta 8192 vértices dan L/τ = 38.4, 155.6 y 622.7 en profundidades 1, 2, 3 (patrón (2,3), f = 1/2), estables al 0.03 % al duplicar la resolución. Son cotas superiores verificadas numéricamente para polígonos explícitos, no grosores suaves certificados. No se afirma estacionariedad, optimalidad ni ley de flujo recursiva.

## Detalles de la prueba asistida del caso d = 2 (trasladados del manuscrito en v0.6)
